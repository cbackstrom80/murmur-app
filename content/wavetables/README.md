# content/wavetables/

Factory wavetable data, built with `pw8-wavetable-builder` (see
`tools/wavetable_builder/`). Empty in this pass -- no factory tables are shipped yet.
The wavetable oscillator itself (`pw8::oscillator::WavetableOscillator`) is
implemented and tested; only factory content is missing. See
`docs/DSP_ENGINE.md` "Wavetable" for the current PARTIAL status (no mip-mapping yet).
