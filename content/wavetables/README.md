# content/wavetables/

Factory wavetable data, built with `murmur-wavetable-builder` (see
`tools/wavetable_builder/`). 51 tables: the original `basic_harmonic.json`
(UI GATE 5 era) plus a 50-table general library and 10 `gran-*` tables for
the Granular engine, generated by `scripts/generate_wavetable_library.py`.
See `MANIFEST.md` in this directory for the full list with categories/mood
tags, or `docs/DSP_ENGINE.md` "Wavetable" / "Granular" for implementation
status.

Source WAVs (the raw synthesized input each `.json` table was built from --
regenerate a table by re-running the builder against these if
`murmur-wavetable-builder` itself ever changes) live under `sources/`.
