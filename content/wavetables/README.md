# content/wavetables/

Factory wavetable data, built with `pw8-wavetable-builder` (see
`tools/wavetable_builder/`). 51 tables: the original `basic_harmonic.json`
(UI GATE 5 era) plus a 50-table library generated by
`scripts/generate_wavetable_library.py`. See `MANIFEST.md` in this directory
for the full list with categories/mood tags, or `docs/DSP_ENGINE.md`
"Wavetable" for the oscillator/mip-mapping implementation status.

Source WAVs (the raw synthesized input each `.json` table was built from --
regenerate a table by re-running the builder against these if
`pw8-wavetable-builder` itself ever changes) live under `sources/`.
