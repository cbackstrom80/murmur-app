Hi Ben,

New build ready — **1.5.0** is the one to install. Biggest changes: redesigned **Design FX** panel (card browser + chain + live hero viz), **Quasar** spatial master section, and new **Blades / MasterSpatial / Streams** preset banks.

**Download:** `MURMUR-1.5.0-macOS-arm64-full.dmg` from GitHub Releases.

## Install

1. Open the DMG → double-click **Install MURMUR.pkg**
2. **Quit Logic completely** (Cmd+Q), reopen
3. **Logic → Settings → Plug-in Manager → Reset & Rescan Selection**
4. New track → **AU Instruments → Murmur → MURMUR**

## Things to try

Press **⌘B** (or click **BROWSE**):

- **Interstellar:** category **INTERSTELLAR** → **CATHEDRAL NEBULA**
- **Spatial:** category **MASTER SPATIAL** → **NEBULA DRIFT**
- **Blades:** category **BLADES** → **SERIAL SWEEP**

Switch to **DESIGN** mode → **FX** tab to see the new card browser and chain view. Click a card to open the detail panel with live hero visualizer.

Full demo list installs to `~/Library/Application Support/MURMUR/Docs/BEN_DEMO_PRESETS.md`.

Let me know how it goes!
