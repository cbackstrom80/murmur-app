Hi Ben,

Quick update — please use **1.4.4** instead of 1.4.3. This fixes the Logic plug-in not appearing after install, and the preset browser filters.

**Download:** `MURMUR-1.4.4-macOS-arm64-full.dmg` from GitHub Releases.

## Install

1. Open the DMG → double-click **Install MURMUR.pkg**
2. **Quit Logic completely** (Cmd+Q), reopen
3. **Logic → Settings → Plug-in Manager → Reset & Rescan Selection**
4. New track → **AU Instruments → Murmur → MURMUR**

## Presets to try

Press **⌘B** (or click **BROWSE**):

- **Interstellar:** category **INTERSTELLAR** → **CATHEDRAL NEBULA** (hold a chord, sweep mod wheel)
- **Hoover bass:** category **BASS** → CONTEXT chip **Hoover-bass** → **CLUB HOOVER**

Full demo list installs to `~/Library/Application Support/MURMUR/Docs/BEN_DEMO_PRESETS.md`.

Let me know how it goes!
