# MURMUR 1.4.4 — Ben hotfix (AU install + preset browser)

**Apple Silicon Macs**, **macOS 13+**, **Logic Pro**.

Replaces 1.4.3 — use this build for Ben.

## Install

1. Download **`MURMUR-1.4.4-macOS-arm64-full.dmg`**
2. Double-click **`Install MURMUR.pkg`**
3. **Quit Logic completely**, reopen
4. **Plug-in Manager → Reset & Rescan Selection**
5. **⌘B** to open Preset Explorer

## Fixes in 1.4.4

- **AU installs correctly** — standalone app no longer steals the Audio Unit during pkg install
- **Preset browser defaults to ALL PRESETS** — MOOD / CONTEXT / TAG filters visible again (was stuck on empty Favorites)
- **Hoover + Interstellar discovery** — genre/tag cross-filter; demo guide in Docs
