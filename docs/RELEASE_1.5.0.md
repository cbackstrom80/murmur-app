# MURMUR 1.5.0 — Design FX + MI sprint (Ben install)

**Apple Silicon Macs**, **macOS 13+**, **Logic Pro**.

Replaces 1.4.4 — use this build for Ben.

## Install

1. Download **`MURMUR-1.5.0-macOS-arm64-full.dmg`**
2. Double-click **`Install MURMUR.pkg`**
3. **Quit Logic completely**, reopen
4. **Plug-in Manager → Reset & Rescan Selection**
5. **⌘B** to open Preset Explorer

## What's new in 1.5.0

### Design FX (Figma-aligned)
- **Card browser** — browse effects as cards with mini viz, knobs, and ON toggles
- **Chain view** — signal-routing strip with drag-reorder slots
- **Detail panel** — 280px controls + 448px hero viz per effect
- **CPU hero visualizers** — live per-effect plots (saturation, chorus, reverb, compressor, EQ, etc.)

### Master + spatial
- **Quasar panel** — binaural spatial chain UI (Figma 102:4)
- **MasterSpatial** factory bank (20 cinematic spatial presets)
- **Master dynamics** — compressor/limiter engine groundwork

### Mutable Instruments integration
- **Blades** filter routing lab + 15 factory presets
- **Streams** dynamics lab + 10 factory presets
- **Design labs** — envelope segments, morph editor, generative sources, Peaks utility
- **Filter routing** wireframe + engine tests

### Presets + content
- **1129+ factory presets** including updated Interstellar Spatial bank
- Wavetables, design-FX bundles, and product docs ship with the installer
