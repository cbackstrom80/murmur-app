# MURMUR 1.0.3 — Horizon 1 + DESIGN mode (Weeks 1–2)

Ships **Horizon 1** polish and the first **DESIGN mode** milestones: wavetable warps and algorithm graph editing.

## New in 1.0.3

### Horizon 1
- **Filter 2 MVP** — second filter path in the signal chain
- **Oscilloscope / scope tap** — visual feedback on the output path
- **Mod UX expansion** — clearer modulation routing and editing

### Week 1 — DESIGN shell & warp foundation
- **DESIGN mode shell** — editor layout and navigation for sound-design workflow
- **Wavetable warp foundation** — DSP and state plumbing for bend/asym warps

### Week 2 — Warps & algorithm graph
- **Audible bend/asym warps** — hearable wavetable warp in the engine
- **Algorithm graph editor** — visual operator/routing editor for the 8-engine graph

- Version bump 1.0.2 → 1.0.3

## Install

Download **`MURMUR-1.0.3-macOS-arm64.pkg`** — same Ben MVP flow: double-click, quit Logic, rescan AU, play.
