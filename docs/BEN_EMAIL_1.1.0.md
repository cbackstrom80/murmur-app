### Install (5 minutes)

1. Download **`MURMUR-1.1.0-macOS-arm64.pkg`**
2. Double-click installer (home folder, no admin)
3. **Quit Logic**, reopen, **Reset & Rescan** MURMUR in Plug-in Manager
4. Software Instrument → **AU Instruments → Murmur → MURMUR**

---

### Must-try (15 minutes)

1. **001-nebula-drift** — sweep **Morph** knob; headphones, listen for room/distance morph
2. **Advanced → FX → QUASAR** — toggle Output Mode Headphone vs Speaker; tweak Crossfeed
3. **Sidechain** — send vocal track to MURMUR sidechain, route SIDECHAIN → Filter Cutoff in MOD tab
4. Hold a pad, push delay feedback high — tail should **freeze** (Quasar-style)
