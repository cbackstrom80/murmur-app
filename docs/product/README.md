# MURMUR — Product Documentation

**Eight engines. One voice.**

MURMUR is an algorithmic software synthesizer for macOS — built for deep sound design and immediate performance in the studio. This folder is the **user-facing product guide**; engineering references live in the parent `docs/` directory.
