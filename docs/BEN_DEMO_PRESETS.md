# Ben Demo Presets — Interstellar + Hoover Bass

Quick guide for showing off MURMUR's cinematic and rave bass banks in Logic.

**Open Preset Explorer:** **BROWSE**, click the preset name, or **⌘B**

## Hoover Bass (28 presets)

Classic **90s rave hoover** basses — detuned saws, resonant filter sweeps. Slots **061–088** in the Basses bank.

### Find them in the browser

| Filter | Value |
|--------|--------|
| Category | **BASS** |
| Genre | **hoover-bass** |
| Search | `hoover`, `interstellar`, `cinematic` |

### Start here

| Preset | File | Vibe |
|--------|------|------|
| **CLUB HOOVER** | `Basses/087-club-hoover` | The reference hoover — anthemic sweep |
| **RAVE DRIVE** | `Basses/073-rave-drive` | Aggressive rave pump |
| **ACID SURGE** | `Basses/062-acid-surge` | Resonant acid-tinged hoover |
| **PUMP RUSH** | `Basses/074-pump-rush` | Fast filter rush for drops |
| **TURBINE BLAST** | `Basses/085-turbine-blast` | Wide detune, big room |

Play **C1–C2**, short staccato or sustained — sweep **mod wheel** and macro knobs for filter motion.

## Suggested 10-minute set for Ben

1. **CATHEDRAL NEBULA** — hold a chord, show mod wheel + macros (cinematic wow)
2. **VOID CATHEDRAL** (Spatial) — headphones, spatial width
3. **CLUB HOOVER** — low note, filter sweep (rave contrast)
4. **CORNFIELD CHASE** — melodic lead, show PLAY scope + master deck
5. Open **BROWSE** → filter **INTERSTELLAR** → scroll the bank count (175)

All of the above are in the factory install — no extra download.
