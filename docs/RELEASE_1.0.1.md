# MURMUR 1.0.1 — Product documentation release

Adds branded **MURMUR product documentation** bundled in the macOS installer.

## New in 1.0.1

- **Product doc set** (`Docs/product/`) — Overview, Quick Start, PLAY Mode, Presets, Sound Design, Performance, Requirements, FAQ
- Installer ships full product guides beside Logic / MP11SE docs
- DMG includes **MURMUR Product Docs.txt** index
- Version bump 1.0.0 → 1.0.1

## Install

Download **`MURMUR-1.0.1-macOS-arm64.pkg`** — same Ben MVP flow: double-click, quit Logic, rescan AU, play.

Product docs after install:

```
~/Library/Application Support/MURMUR/Docs/product/README.md
```

## Unchanged from 1.0.0

- MURMUR Audio Unit, 800 factory presets, wavetables
- MP11SE performance mapping, pad legato fix, Smart Controls guide
